Олон шалгалт — линк хуулах

Шалгалт бүр quizzes/<id>.csv файл + quizzes/manifest.json дахь жагсаалтаар бүртгэгдэнэ. Хадгалалт = Git репо (push → Vercel deploy).

Ачаалж байна…

Нэр Шалгалтын хугацаа Оюутанд өгөх линк
Шинэ шалгалт нэмэх:
  1. quizzes/myquiz.csv файл үүсгэ (баганууд нь өмнөхтэй адил).
  2. quizzes/manifest.json дотор id (латин, тоо, _, -) + title нэм.
  3. Git push хий — Vercel дахин deploy.

Үндсэн шалгалт (quiz.csv): линк дээр ?quiz= байхгүй бол энэ ачаалагдана.

Шалгалтын хугацаа: manifest.json дотор defaultWindow (үндсэн) эсвэл шалгалт бүрийн window — enabled: true, дараа нь шалгалт нээлттэй байх завсар: openAt, closeAt (огноо+цаг, жишээ нь +08:00 бүсээр), message оюутанд гаргах товч тайлбар (сонголттой).
